### 1. 站内搜索（`/search` + Cmd/Ctrl+K 全局命令面板）

- **目标**：全站文章即时搜索，弥补当前仅靠分组浏览的缺口。
- **数据源**：`public/blogs/index.json`（标题/标签/摘要/日期）+ 各文章 `index.md` 正文。
- **方案**：
  - 新增构建脚本 `scripts/gen-search-index.js`，构建期扫描全部文章，生成 `public/search-index.json`（slug、标题、标签、摘要、日期、正文纯文本片段），随部署更新；
  - 搜索页 `src/app/search/page.tsx`：客户端过滤 + 评分，复用博客列表卡片样式，结果高亮关键字，支持上下键选择、回车跳转；
  - 全局面板 `src/components/search-palette.tsx`：挂载到布局层，Cmd/Ctrl+K 唤起，输入即搜。
- **注意**：中文检索建议采用子串匹配 + 二元切分，避免引入过重分词依赖；索引文件需控制体积（正文截断）。
- **工作量**：中。

### 2. 标签页（`/tags`）+ 文章列表标签筛选

- **数据源**：`index.json` 的 tags 字段聚合（数据已具备，无需改发布链路）。
- **方案**：新增 `/tags` 路由，标签云 + 按标签聚合文章列表两种视图，显示各标签文章数；`/blog` 列表页支持 `?tag=` 参数筛选，复用现有 URL 分组参数机制。
- **工作量**：小。

### 3. 归档时间轴（`/archive`）

- **数据源**：`index.json` 按日期分组统计。
- **方案**：年/月双维度时间轴，展示每月文章数与列表、累计篇数；分组逻辑与 `/blog` 列表页共用，避免重复实现。
- **工作量**：小。

### 4. 文章页增强（可拆分为多个独立小项）

- **相关文章推荐**：按共享标签数量排序取 Top N，展示于文末。
- **工作量**：小。

### 5. 暗色模式

- **现状**：主题色为运行时 CSS 变量（`theme.css` + `site-content.json`），天然支持多套主题。
- **方案**：预置「深色」主题色组；切换按钮 + localStorage 记忆，可选跟随系统 `prefers-color-scheme`。
- **注意**：背景图与文章内图片在深色下的观感需逐一检查。
- **工作量**：小。

### 6. 访客统计页（`/stats`）

- **数据源**：`index.json` 全量统计。
- **方案**：纯客户端计算并展示——文章总数、总字数、按年/分类分布、月度更新趋势、热门标签、最长/最短文章；图表用轻量自绘或小型库。
- **可选**：将站点统计替换为 Cloudflare Web Analytics（更轻、隐私友好），替代现有 GA 脚本。
- **工作量**：小–中。

### 7. 工具箱扩展（在现有图片工具箱基础上）

- **二维码生成**：客户端生成（如 qrcode 库），无后端。
- **JSON 格式化 / 校验**：纯客户端。
- **颜色转换**：复用 `src/lib/color.ts` 已有工具。
- **正则表达式测试**：输入即测、高亮匹配。
- **方案**：现有工具箱页扩展为多 tab，或拆分为独立路由。
- **工作量**：中（每项为小）。

### 8. PWA 化

- **方案**：补全 `manifest.json`（名称/图标/主题色）；新增 Service Worker 缓存静态资源（public 内容与构建产物）。
- **注意**：缓存策略需与"内容随部署更新"的发布模型匹配——采用版本化缓存 + 更新提示，避免新文章发布后老用户看到旧内容。
- **工作量**：中。

### 9. 首页小改造

- **首页随机文章卡**：从 `index.json` 随机取一篇展示，带"换一篇"按钮。
- **工作量**：小。
