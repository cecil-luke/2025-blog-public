## 改动记录

- 博客列表默认按月分组：组头带年份和月份，一眼看出文章时期；分类模式日期补充完整年份（`YYYY-MM-DD`），时间分组模式只显示 `MM-DD`，日期等宽对齐、防折行
- 博客列表分组模式同步到 URL（`?mode=`）：切换分组（日/周/月/年/分类）写入 URL，后退/刷新可还原分组状态；默认的月模式不写 URL 参数，保持地址干净
- 修复功能菜单「推荐分享 / 优秀博客」切换偶发失灵：整卡按压缩小（whileTap）使按钮在按下与松开之间发生位移，点击事件落空需要多点几次；已对导航卡、随机推荐卡禁用按压缩小，悬停放大效果保留
