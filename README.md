### 2026-08-16 性能优化与修复

- **代码高亮体积优化**：Shiki 由加载全量语言包改为按站点实际使用的语言白名单加载，且按需加载——文章不含代码块时不加载 Shiki、不含公式时不加载 KaTeX，减少客户端脚本体积与加载时间
- **文章渲染缓存**：Markdown 渲染结果（HTML / 目录 / 代码块）加入缓存（上限 40 条），文章页与编辑器预览共用此链路，重复渲染直接命中缓存，不再重复高亮与解析
- **代码块渲染重构与修复**：代码块不再把整段代码塞进 HTML 属性再转义/反转义（原实现易出错且慢），改为占位符 + 数据数组传递；同时修复 Shiki 不可用降级路径下代码未转义（含 `<`、引号等字符会破坏页面结构）以及降级时代码块空白两个问题
- **文章加载提速**：文章页 `config.json` 与 `index.md` 由串行请求改为并行拉取
- **修复列表数据被污染**：首页「最新文章」原先直接对共享数据数组原地排序，会污染列表缓存，改为拷贝后排序
- **图片加载优化**：文章内图片、封面悬停预览、文章侧栏封面、最新文章封面、图集图片补充 `loading="lazy"` 与 `decoding="async"`，减少首屏加载资源量
- **图床图片墙加载优化**：图片墙由「固定 200ms 节奏 + lazy 加载」改为两段式流水线——后台预加载队列（最多 6 张并发、按顺序提前下载）+ 严格逐张展示（每张间隔 ≥200ms、加载完成才淡入、上一张展示后才轮到下一张）；修复图片多时后段图片加载不及时、多张同时弹出与整体卡顿的问题（4G 模拟下峰值并发请求由 79 降至 6，逐张展示节奏与原来一致）

### 2026-08-18 文章页增强与 Bug 修复

- **阅读进度条**：新增 `reading-progress.tsx` 组件，顶部固定进度条监听 `document.scrollingElement` 滚动事件，用 `width` 百分比驱动进度条宽度；进入文章页时 `window.scrollTo(0, 0)` 重置滚动位置
  - **修复进度条始终为 0**：Tailwind v4 的 `scale-x-0` 类使用 CSS `scale` 属性，优先级高于 JS 设置的 `transform: scaleX()`，导致进度条视觉宽度永远为 0；改用 `width` 百分比驱动，彻底避免 CSS 属性冲突
- **字数与阅读时长**：Markdown 渲染时统计中英文混合字数（中文按字、英文按词），以 450 字/分钟预估阅读时长，显示在文章日期旁；新增 `getReadingStats()` 函数，剥离代码块/图片/公式等非正文内容后统计
- **上一篇/下一篇导航**：基于 `index.json` 日期排序取相邻文章，文末双栏导航卡片，支持快速切换文章
- **移动端目录**：新增 `mobile-blog-toc.tsx` 组件，移动端悬浮「目录」按钮 → 底部抽屉式 TOC；`DialogModal` 新增 `overlayClassName` prop 支持底部对齐布局
- **Heading ID 去重**：新增 `slugifyUnique()` 函数，重复标题自动加 `-1`、`-2` 后缀；ID 预生成并 stash 到 token 上，保证 HTML heading ID 与 TOC ID 一致；`blog-toc.tsx` 的 key 改为 index-based 以兼容重复 heading
- **修复 React 重复 key 警告**：`<BlogPreview key={slug}>` 和 `<ReadingProgress key={slug}>` 在同一 Fragment 下产生重复 key（`Encountered two children with the same key`），移除 `ReadingProgress` 上的 key

### 1. 站内搜索（`/search` + Cmd/Ctrl+K 全局命令面板）

- **目标**：全站文章即时搜索，弥补当前仅靠分组浏览的缺口。
- **数据源**：`public/blogs/index.json`（标题/标签/摘要/日期）+ 各文章 `index.md` 正文。
- **方案**：
  - 新增构建脚本 `scripts/gen-search-index.js`，构建期扫描全部文章，生成 `public/search-index.json`（slug、标题、标签、摘要、日期、正文纯文本片段），随部署更新；
  - 搜索页 `src/app/search/page.tsx`：客户端过滤 + 评分，复用博客列表卡片样式，结果高亮关键字，支持上下键选择、回车跳转；
  - 全局面板 `src/components/search-palette.tsx`：挂载到布局层，Cmd/Ctrl+K 唤起，输入即搜。
- **注意**：中文检索建议采用子串匹配 + 二元切分，避免引入过重分词依赖；索引文件需控制体积（正文截断）。
- **工作量**：中。

### 2. 标签页（`/tags`）+ 文章列表标签筛选

- **数据源**：`index.json` 的 tags 字段聚合（数据已具备，无需改发布链路）。
- **方案**：新增 `/tags` 路由，标签云 + 按标签聚合文章列表两种视图，显示各标签文章数；`/blog` 列表页支持 `?tag=` 参数筛选，复用现有 URL 分组参数机制。
- **工作量**：小。

### 3. 归档时间轴（`/archive`）

- **数据源**：`index.json` 按日期分组统计。
- **方案**：年/月双维度时间轴，展示每月文章数与列表、累计篇数；分组逻辑与 `/blog` 列表页共用，避免重复实现。
- **工作量**：小。

- **相关文章推荐**：按共享标签数量排序取 Top N，展示于文末。
- **阅读进度条** ✅（已实现，见 2026-08-18 改动记录）：顶部滚动进度指示，用 width 百分比驱动避免 CSS 属性冲突。
- **字数与预计阅读时长** ✅（已实现，见 2026-08-18 改动记录）：基于正文文本统计，中文按字、英文按词。
- **移动端目录** ✅（已实现，见 2026-08-18 改动记录）：悬浮目录按钮 + 底部抽屉式 TOC。
- **工作量**：小–中（每小项可单独交付）。

### 5. 暗色模式

- **现状**：主题色为运行时 CSS 变量（`theme.css` + `site-content.json`），天然支持多套主题。
- **方案**：预置「深色」主题色组；切换按钮 + localStorage 记忆，可选跟随系统 `prefers-color-scheme`。
- **注意**：背景图与文章内图片在深色下的观感需逐一检查。
- **工作量**：小。

### 6. 访客统计页（`/stats`）

- **数据源**：`index.json` 全量统计。
- **方案**：纯客户端计算并展示——文章总数、总字数、按年/分类分布、月度更新趋势、热门标签、最长/最短文章；图表用轻量自绘或小型库。
- **可选**：将站点统计替换为 Cloudflare Web Analytics（更轻、隐私友好），替代现有 GA 脚本。
- **工作量**：小–中。

- **方案**：现有工具箱页扩展为多 tab，或拆分为独立路由。
- **工作量**：中（每项为小）。

### 8. PWA 化

- **方案**：补全 `manifest.json`（名称/图标/主题色）；新增 Service Worker 缓存静态资源（public 内容与构建产物）。
- **注意**：缓存策略需与"内容随部署更新"的发布模型匹配——采用版本化缓存 + 更新提示，避免新文章发布后老用户看到旧内容。
- **工作量**：中。
