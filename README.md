## 改动记录

### 2026-08-20 雪花背景组件性能优化 + Bug 修复

- **架构重构为单例引擎**：所有 `SnowfallBackground` 实例共享单一 `requestAnimationFrame` 循环与指针事件监听器，双实例场景下每帧计算量减少 50%
- **渲染优化**：交互反馈从 `drop-shadow`（合成器重计算）改为 `opacity`（纯 GPU 混合），`will-change` 从 `transform, filter` 改为 `transform, opacity`，降低 GPU 开销
- **资源自动回收**：最后实例卸载时自动停止动画引擎、移除事件监听器
- **修复复制粘贴导致的死代码**：`else` 分支内存在不可达的 `if` 块，交互缩放效果丢失
- **修复事件监听器泄漏**：清理函数正确执行 `removeEventListener`，避免重复挂载后监听器堆积
- **修复首帧 deltaTime 爆炸**：用 `null` 标记未初始化状态，跳过首帧物理更新
- **修复页面重新可见时跳帧**：检测 `deltaTime > 100ms` 则跳过该帧，避免标签页切换后雪花位移异常
- **恢复淡入动画**：组件挂载后 `opacity` 从 0 过渡到 1，持续 1 秒
- 涉及文件：`src/layout/backgrounds/snowfall.tsx

### 2026-08-18 图床缩略图优化（移动端图片展示丝滑化）

- **问题**：移动端图床照片墙越往后越卡。原因是照片墙里每张图都加载的是高清原图（1080–1200px、共约 27MB），但屏幕上实际只显示 200px 大小，手机内存扛不住，导致不断卡顿。
- **方案**：照片墙改为加载小缩略图（600px 宽，总体积仅约 4.8MB，是原来的 1/5），点击放大时才加载原图保证清晰。上传图片时浏览器自动生成缩略图一并提交，删除时也一并清理。
- **效果**：图片加载速度大幅提升，滑动流畅不卡顿，内存占用降到原来的 1/4。
- 涉及文件：`scripts/gen-picture-thumbs.js`（批量生成缩略图）、`src/app/pictures/components/` 下散落墙与串线墙组件、`src/lib/file-utils.ts`（缩略图生成）、上传/删除服务。
- **生效方式**：重新部署即可；以后上传/删除图片缩略图全自动处理。

### 2026-08-18 站内搜索 + 全局命令面板

- **功能**：支持全站文章搜索。桌面端按 Cmd/Ctrl+K 弹出搜索面板，也可以在博客列表页点击「搜索」按钮；移动端右下角有搜索按钮。
- **搜索范围**：文章标题、标签、摘要、正文全文都可搜到，搜索结果会高亮匹配的关键字并显示上下文片段。
- **搜索结果排序**：标题匹配的文章排最前面，其次标签匹配，再是正文匹配；越新的文章越靠前。多个关键词用空格分隔，要求同时匹配。
- **命令面板**：弹窗内输入即搜，上下键选择、回车打开文章、Esc 关闭。会记住你最近搜索过的关键词。
- **搜索页**（`/search`）：独立的搜索结果页面，展示完整列表，URL 中的搜索词刷新后不会丢失。
- 涉及文件：`scripts/gen-search-index.js`（构建时生成索引）、`src/lib/search.ts`（搜索逻辑）、`src/components/search-palette.tsx`（命令面板）、`src/components/highlight-text.tsx`（关键字高亮）、`src/app/search/page.tsx`（搜索页）。
- 改动文件：`src/layout/index.tsx`（挂载面板 + 移动端搜索按钮）、`src/app/blog/page.tsx`（博客列表页搜索按钮）、`package.json`（新增构建脚本）。
- **生效方式**：构建时自动生成搜索索引，部署后即可使用。索引在用户首次打开搜索时才加载，不影响页面打开速度。

## 未完成开发计划

### 1. 归档时间轴（`/archive`）

- **数据源**：`index.json` 按日期分组统计。
- **方案**：年/月双维度时间轴，展示每月文章数与列表、累计篇数；分组逻辑与 `/blog` 列表页共用，避免重复实现。
- **工作量**：小。

### 2. 文章页增强（可拆分为多个独立小项）

- **相关文章推荐**：按共享标签数量排序取 Top N，展示于文末。
- **工作量**：小。

### 3. 访客统计页（`/stats`）

- **数据源**：`index.json` 全量统计。
- **方案**：纯客户端计算并展示——文章总数、总字数、按年/分类分布、月度更新趋势、热门标签、最长/最短文章；图表用轻量自绘或小型库。
- **可选**：将站点统计替换为 Cloudflare Web Analytics（更轻、隐私友好），替代现有 GA 脚本。
- **工作量**：小–中。

### 4. 工具箱扩展（在现有图片工具箱基础上）

- **二维码生成**：客户端生成（如 qrcode 库），无后端。
- **JSON 格式化 / 校验**：纯客户端。
- **颜色转换**：复用 `src/lib/color.ts` 已有工具。
- **正则表达式测试**：输入即测、高亮匹配。
- **方案**：现有工具箱页扩展为多 tab，或拆分为独立路由。
- **工作量**：中（每项为小）。

### 5. PWA 化

- **方案**：补全 `manifest.json`（名称/图标/主题色）；新增 Service Worker 缓存静态资源（public 内容与构建产物）。
- **注意**：缓存策略需与"内容随部署更新"的发布模型匹配——采用版本化缓存 + 更新提示，避免新文章发布后老用户看到旧内容。
- **工作量**：中。

### 6. 首页小改造

- **首页随机文章卡**：从 `index.json` 随机取一篇展示，带"换一篇"按钮。
- **工作量**：小。
